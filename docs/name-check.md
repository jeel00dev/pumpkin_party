# Name check

Every new player-facing name, what was checked, and what couldn't be verified.

**This isn't legal clearance.** These are quick web searches for obvious conflicts. They aren't trademark searches, and they don't cover every country. A proper search of the final name list is on the owner's list.

## Banned names

These must not ship. `tests/terms.test.js` fails if any of them appears in the source.

| Name | Why | Used instead |
|---|---|---|
| Ouija | Hasbro trademark | Spirit Board |
| Pumpkin King | Strongly tied to an existing character | Not chosen yet (rank ladder, Milestone 5) |
| Monster Mash | Song title | Graveyard Gang (bundle). Rhythm game name pending (Milestone 2) |
| Friday the 13th | Film franchise | Not chosen yet (event, Milestone 5) |

## Checked names

| Name | Used for | Checked (2026-11-05) | Result |
|---|---|---|---|
| Pumpkin Party | The game | Web search for browser, CrazyGames, Poki and Steam listings | **Not unique.** Two small itch.io games use it (by Joseph Ferrari and brinjaw), and nodal.gg lists a game with this name. No CrazyGames or Poki listing found. Owner decision: keep or rename |
| Spirit Board | Round reveal | Web search | Generic. Sources use "spirit board" and "talking board" for the general object, while Ouija is the brand |
| Spared, Spooked | Replace "Qualified" and "Eliminated" | Ordinary English words, used here as plain verbs | No search made. Low risk |
| Golden Treat | The winner's prize, replacing the crown | Web search | No game or trademark found under this exact name. It sounds close to the Wonka "Golden Ticket", but it's a different phrase |
| Trick or Treat | The choice at reveals | Common phrase | No search made. Generic Halloween phrase |
| Graveyard Gang | Shop bundle, replacing "Monster Mash" | Web search | No game or trademark found. *The Graveyard Gang* is a 1993 children's novel by James Duffy, which is a different field |
